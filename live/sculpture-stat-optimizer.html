Core Facts & Provenance:

  • Canonical Stat Order: Strength → Health → Dexterity → Agility is strictly preserved across all tables, formulas, and calculations.
  • Stat Drop Chance: statDrop.chance from core/data/formulas/economy.json:
    N = pow(25*(statValue + 1), 0.4) * breakpoint(statValue > 1e6) / (1 + statBoost) / (1 + statSpecific)
    Where breakpoint = 1 + 2*(statValue - 1000000)/1000000 past 1 million stats. Confirmed independently via official patch notes PATCH 1.2.3.0.
  • Sanctum Modifier Scaling: core/data/tables/modifier-tiers.json & roll-coefficients.json:
    Roll formula: pow(max(iLevel - 100, 1), 0.49) × levelMultiplier × tierMultiplier.
    Stat Rate multiplier = 0.001 (e.g. at iLevel 78189, T13 → 91.57%).
    Specific Stat Drop multiplier = 0.005 (exactly 5× higher, e.g. 457.85%).
  • Sculpture Roll Coefficients: core/data/tables/roll-coefficients.json:
    statStrength/statHealth/statDexterity/statAgility levelMultiplier = 0.005.
    stat (global stat rate) levelMultiplier = 0.001 (exactly 5× lower).
    partnerExperience levelMultiplier = 0.0005 (exactly 10× lower).
  • Partner Speed Curve: core/data/formulas/partners.json:
    Speed interval: seconds = 18 / (0.1 + Speed / (Speed + 10000)). Hard floor 16.36s.
